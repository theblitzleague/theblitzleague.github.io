# The Blitz League Hub

Static web hub for The Blitz League (12-team Sleeper dynasty league). No build step and no server code:
plain HTML/CSS/JS that reads the commissioner's data files and Sleeper's public read-only API.

## Run it locally
    cd blitz-league-hub && python3 -m http.server 8731
    # open http://localhost:8731/
`fetch()` doesn't work from `file://`, so it needs the little server.

## Installable app and hosting
- **App:** the hub is an installable web app (PWA). `manifest.webmanifest` (name, colors, icons), `sw.js` (offline copy:
  pages/data network-first, `assets/` cache-first; bump `VERSION` to clear), icons in `assets/icons/` (made from the shield).
  Phones: open the site, then Share > Add to Home Screen (iPhone) or Install app (Android). The service worker registers only
  on https and not inside an iframe (so not in the claude.ai preview).
- **Hosting plan:** GitHub Pages at https://theblitzleague.github.io (repo named `theblitzleague.github.io` under the
  `theblitzleague` account), with GitHub Actions for the daily data jobs. Not set up yet.
- **Never published** (`.gitignore`): `assets/source/`, `assets/league/*-src.*`, `assets/league/*-full.*`. The as-sent
  BN mark PNG carries C2PA generator metadata; the web copies the site uses carry none.

## Files
- `data/league.json`: league settings and divisions. **`sleeperLeagueId` is null, so the site runs on sample data.**
- `data/franchises.json`: branding per Sleeper `roster_id` (location, colors, helmet colors, logo paths, GM, past GMs). Commissioner-only.
- `assets/league/championship-trophy.webp`: the championship trophy from the commissioner (2026-11-04), as a 640px web copy; the original 1024x1536 is `championship-trophy-full.webp`. `league.json` `trophy` points at it. It's shown in the Almanac's Champions trophy case (a name plate per season) and as a "Playing for" strip on the Playoff Race tab.
- `data/history.json`: completed seasons (records, PF/PA, GM's Sleeper user ID, champion, runner-up, division winners). Built by `tools/build_history.py` from Sleeper's league chain (previous_league_id + winners_bracket); run it once after each championship. From it, `js/data.js` builds GM careers keyed by Sleeper user ID, so titles and career record / PF / PA follow the GM between franchises (Front Office: honors rack to the right of the portrait, only honors actually won), and franchise honors stay with the team (History tab). The Almanac's trophy plates and Seasons table read it too.
- `data/sample/`: placeholder data in Sleeper's API shapes, built by `tools/build_sample.py`. Player info is real Sleeper data; rosters (a snake draft of real players over Sleeper's search rank), weekly scores, trades and picks are invented. Week 9 is half-scored to show the "live" state. Rosters use the real Blitz League lineup from Sleeper (QB, 2 RB, 2 WR, TE, 2 FLEX, Superflex, K, DL, LB, DB, IDP Flex; 10 bench, 3 taxi), 24 active players each, and the sample starts healthy players first. Defenders are grouped DL / LB / DB the way lineups are: `js/data.js` turns Sleeper's exact spot (DE, CB, OLB...) into the group as `position` and keeps the spot as `nflPos`. The depth chart puts the defense across the line of scrimmage from the offense. `tools/add_bench_points.py` then adds Sleeper's `players_points` (bench scores, invented) without changing any game score; run it after every rebuild.
- `js/data.js`: loads sample or live data (incl. drafts) into one model. `js/ui.js`: shared helpers (formatting, colors, page boot, league header). One script per page: `home.js`, `standings.js`, `teams.js`, `team.js`, `matchup.js`, `draft.js`, `awards.js`, `almanac.js`, `map.js`.
- `js/us-map.js`: US state outlines, generated by `tools/build_map.py` from us-atlas@3.0.1 (`states-albers-10m.json`).
- `league.json` also holds the candidate `locations` (lat/lon) for the map, and per-division `inkOnDark` / `markOnDark` colors for the dark site.
- Archived seasons go in `franchises.json` → `seasons` per franchise (`[{season, wins, losses, ties, pf, pa, result}]`, result `champion`/`runner-up`/`playoffs`/`missed`). Franchises and Almanac read them. `js/helmet.js`: the recolorable helmet and the placeholder shield mark.
- `assets/logos/`: drop the designer's SVG/PNG files here, then point `logos.*` in `franchises.json` at them.

## Going live (once the league exists)
1. Put the league ID in `data/league.json`.
2. Build a trimmed `data/players.json`. Sleeper's full player database is about 15 MB and Sleeper asks that it be pulled at most once a day, so visitors' browsers must not fetch it directly. `tools/build_players.py` does it (written 2026-11-04): keeps fantasy positions incl. IDP for players on an NFL team plus anyone on a league roster, about 2,200 players / 409 KB (68 KB gzipped). `--from FILE` rebuilds from a saved download instead of pulling again. Run it once a day.
3. Live mode in `js/data.js` is written but **untested** until there's a real league ID.
4. Roster slots and divisions then come from Sleeper (`roster_positions`, `roster.settings.division`), not the placeholders.

## Awards race (`awards.html`)
Everything is computed from finished games only.
- **Lineup IQ** = points started / best legal lineup from that week's roster (needs Sleeper `players_points`). Bench Warmer = most points left on the bench.
- **Playoff odds**: 10,000 seeded simulations of the remaining schedule. Each team scores around its real average, pulled toward the league average early in the season, with the league's week-to-week spread. The seed is season+week, so the numbers only change when a week changes. Clinched/Eliminated are proven from records, not the simulation.
- **Playoff format**: `league.json` `playoffTeams` (6, no byes). In live mode Sleeper's `settings.playoff_teams` overrides it. Seeding is by record, with points-for as the tiebreak.
- **Prize money**: `league.json` `prizes` (buy-in, champion, runnerUp, division, weekly, pointsLeader, gmOfYear, honorsOnly). `UI.cash(n)` draws the gold chip beside each award, and `UI.weeklyWinners(M)` finds each regular-season week's high score (ties split). The Prize money tab (`#prizes`) checks that the payouts add up to buy-in × teams and says so if they don't.
- **Career earnings**: `js/data.js` adds up every prize a GM has won (`careers[gm].earnings`, `.won`) from history.json (champion, runnerUp, divisionWinners, weeklyHigh, pointsLeader, gmOfYear, at that season's `prizes` copy) plus this season's weekly prizes already won. Shown on the team page's Earnings tab (won, buy-ins, net, by prize, by season), as a Front Office stat, and as the all-time list on Awards → Prize money. GM of the Year is a vote: put the winner's roster_id in that season's `gmOfYear` in history.json.
- **Blitz Network** (home): stories from `data/news.json` (see its `_readme`; `breaking: true` puts one in the ticker) plus an automatic wire built from results in `js/home.js` `wire()`. The network name/logo are `league.json` `network`: `logo` (full wordmark) and `mark` (BN square, used as art for stories with no team). The site uses the white-text `*-white.webp` versions because the navy originals vanish on the dark background; `blitz-network.webp` / `blitz-network-mark.webp` keep the original navy for light backgrounds, and `*-src.*` are the files as sent.
- **Schedule** (`schedule.html`, `js/schedule.js`): the league-wide regular season. `#w<week>` = By week (defaults to the current week): every game as a card with billing chips and the line (finished games: closing spread and who covered), plus that week's high score and prize. `#grid` = Team grid: each team's opponent every week, W/L colored, division games underlined, this week highlighted; phones open scrolled to this week. Each team page still has its own Schedule tab.
- **Game billing** (`UI.billingHTML`, above the status badge on the home Game of the Week and the matchup page): the week, then chips only when true: division game (division color), 1st place on the line (the division's current 1st vs 2nd; not shown on final games), rematch (their latest earlier final meeting). Playoff round names are not in yet: the hub only loads regular-season weeks, and naming the title game needs Sleeper's winners bracket.
- **Broadcast and line**: `UI.broadcastHTML` ('Watch on' + network logo or wordmark) and `UI.oddsHTML` / `UI.line` on every matchup. The line uses only weeks finished before the game, so final games show the closing line, plus covered and over/under. It's the site's projection, for fun, not a sportsbook.
- **GM Index** = `league.json` `gmIndexWeights` blend of win %, Lineup IQ and moves value, each scaled 0-100 across the league. GM of the Year itself is a league vote at season's end.

## Player card (`js/player.js`)
Click (or Enter on) any element with `data-pid` (use `UI.pid(id)`) to open a player's game log. Stats come from
`api.sleeper.com/stats/nfl/player/{id}?season_type=regular&season={yyyy}&grouping=week`: the endpoint the Sleeper app uses.
It's **not in Sleeper's documented API** and could change without notice, so the card fails soft. Fantasy points use the
league's own `scoring_settings` in live mode (and the league's `players_points` for rostered weeks), and Sleeper's default
PPR / IDP points in sample mode. Columns follow the player's position; columns empty all season are hidden.
If Sleeper can't be reached (the claude.ai preview blocks outside requests) or the call fails, the card falls back to
`data/stats/<season>.json`, a saved copy of every rostered player's game log built by `tools/build_stats.py`
(about 75 s for 222 players and 2 seasons; run it daily). The card says when it's showing the saved copy.
